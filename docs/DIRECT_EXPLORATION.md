# 직접 탐색

## 서울 주민의 시작과 첫 의뢰

새 세이브는 인물 선택 전에 네 장의 간단한 일러스트 서사를 본다. 서울의 일상이 무너진 상황, 도시에 남아 생존하겠다는 결심, 부족한 물자와 도움의 필요, 약탈자들에게 들은 지역 실권자들의 순서다. 이전/다음/건너뛰기를 지원하고 현재 페이지를 저장한다. 기존 플레이어에게 강제 재생하지 않으며 설정의 처음 안내 다시 보기로 감상할 수 있다.

황 상사·보건의 최씨·용산 김씨 중 찾아갈 인물을 선택하면 바로 첫 의뢰 대화로 연결된다. 황 상사는 포켓 물자로 수색 능력을 확인하고, 최씨는 의료 물자와 주변 상황을 조사해 달라고 부탁하며, 김씨는 공구상자의 수리 물자를 확인한다. 의뢰 수락 후 권총 지급 대화가 이어진다. 첫 의뢰 중 용산의 첫 사건은 해당 종류의 상자이며, 물품 하나를 골라 생존 귀환한 뒤 보고하면 **25,000원과 선택한 NPC 신뢰도 2**를 한 번 지급한다. 수색 중 확보한 의료품 등을 현장에서 써도 조사 사실은 유지되지만, 사망·탈진·긴급 귀환하면 그 시도의 의뢰 목표는 인정하지 않는다. 재시도할 수 있다.

홈과 탐색에는 다음 행동만 짧게 안내한다. 보고 준비 상태와 완료 상태는 일일 의뢰와 별도로 저장한다. 저장 실패 시 수락/권총 지급을 롤백하고, 재시도 후 필요한 대화를 다시 연다.

## 상자 파밍

모든 사건에는 전투 전리품 또는 발견 물자를 확보할 기회가 있다. 비전투 발견 시 **공구상자·의료상자·총기상자·탄약상자·포켓·금고** 중 하나를 표시한다. 열어서 두 후보 중 하나를 고르거나, 눈에 띄는 물건을 바로 챙길 수 있다. 적을 피한 경우도 주변 물자 선택으로 이어지므로 빈 결과로 경로 선택에 넘어가지 않는다.

경로 두 개에 다음 상자 단서를 함께 표시한다. 종류별 실제 아이템 풀과 수량을 사용하고 탄약은 탄종을 표시한다. 후보는 사건 진입 시 저장해 재접속으로 재추첨되지 않으며, 선택한 아이템만 한 번 가방에 넣고 획득 결과를 보여준다. 현재 상자를 고르는 동안은 전투 시간이 멈춘다. 의료상자에는 실제로 사용할 수 있는 치료 물자를 넣었다. 전리품의 기지 정산은 기존처럼 생존 탈출 시에만 수행한다.

홈의 **직접 탐색하기**에서 시작한다. 첫 의뢰를 수락하면 선택한 NPC가 본편의 말투로 권총을 건네는 대화가 열린다. **권총 받기**를 누르면 첫 보급품을 지급하고 빈 총기 칸에 P17을 착용한다. 보유 중인 기본 치료제·음식·물·호환 탄약은 출발 물자로 미리 선택되며, 출발할 때만 창고에서 차감한다. 가져갈 물자 메뉴에서 바꿀 수 있다. 기존 장착 총기는 바꾸지 않고, 지급 준비 완료를 저장하여 반복 수령을 막는다.

황 상사는 군수 불출과 생환, 최 선생은 상처와 식사, 용산 김씨는 총기 점검과 돌아온 뒤의 사용 후기를 중심으로 말한다. 본편 `TRADER_*_CHAT` 대사를 참고해 새 장면을 작성했다. 아직 열리지 않은 지역은 목록에 만들지 않는다. 열린 지역에서 무기 미착용이면 장비 선택창으로 연결한다.

## 플레이 흐름

직접 탐색은 본편 `Program.Progression.IsRaidMapAvailable`의 정찰 경로 순서인 **용산 전자상가 → 구로 공장 → 한강 → 남산 숲 → 강남 → 용산 기지**를 따른다. 앞 지역에서 한 번 생존 탈출하면 다음 지역을 개방하며, 중간 탈출도 인정한다. 주요 경로 여섯 곳에서 모두 생존 귀환하면 별도 지역 **명동·의정부**가 함께 열린다. 사망·탈진·긴급 구조는 해금 조건에 포함하지 않는다. 본편의 퀘스트 완료 조건은 모바일 직접 탐색의 생존 귀환으로 대체한다.

`SurvivedExplorationMapIds`를 저장하며, 기존 세이브의 마지막 성공 결과도 보존한다. 과거에 저장하지 않았던 이전 탐색 이력은 추정하지 않는다. 직접 탐색의 지역 제한은 계정 레벨/신뢰도와 분리하며, 기존 스캐브 파견의 해금 조건은 유지한다. 용산 기지를 모바일 지역 데이터에 추가했고, 전리품 표와 파견 예산은 같은 해금 레벨의 의정부 자료를 공유한다.

한 판은 출발 때 정해지는 6~10개 사건이다. 스캐브/PMC 발소리에 대응하거나 매장과 건물을 수색한다. 사건이 끝나면 길 두 개 중 다음 목적지를 고른다. 중간에 한 번 이상, 마지막에는 반드시 탈출구가 나온다. 탈출구에서 귀환하면 전리품을 보존한다.

교전은 실시간이다. 적이 조준하는 동안 엄폐하고 재장전이나 부상 시 공격한다. 총기별 단발/점사/연사와 실제 호환 탄약을 사용하며, 탄창을 소진하면 추가 재장전 시간이 든다. 별도 근접 슬롯은 탄약이 없는 상황에서도 사용할 수 있다. 아이템 메뉴는 선택 중 전투를 멈추지만 실제 치료는 전투 시간에 진행한다.

이동은 수분 12와 에너지 14를 소모한다. 수분 25 미만이면 공격 간격이 늘어나고, 에너지 0이면 이동할 수 없다. 음식·물 또는 긴급 귀환으로 빠져나올 수 있으며 둘 다 0이면 강제 귀환한다. 비는 양측 청취/발견 확률, 안개는 양측 명중률에 같은 계수를 적용한다.

성공 결과는 녹색, 사망 결과는 빨간색으로 구분한다. 성공 시 아이템 목록, 사망 시 상대와 사용 무기 및 잃은 전리품을 보여준다. 구조 귀환 시 페이드 전환 뒤 선택한 메인 NPC가 대사를 한다. 실패해도 장착 장비와 남은 출발 보급품은 보존된다. 기지의 치료·식사로 다음 탐색을 준비한다.

## 저장과 기존 기능

- 탐색 시드·적 행동·남은 예고 시간·자원·소모품·전리품을 저장한다. 앱이 숨겨지거나 도움말이 열리면 교전을 멈춘다.
- 입력은 저장 성공과 함께 확정하며 실패하면 해당 조작의 변경을 되돌린다. 전투는 매초 및 백그라운드 전환 때 저장한다.
- 동일 지역에 스캐브 파견과 직접 탐색을 동시에 진행할 수 없다. 초도 보급 파견에도 적용한다.
- 귀환 보상은 한 번만 정산한다. 창고가 가득 차면 별도 보관하며 준비 화면에서 수령한다.
- 기존 Player.Level/Exp 및 스캐브 파견의 해금 조건은 유지한다. 직접 탐색은 위 생존 귀환 순서를 사용한다. 별도 CharacterLevel/CharacterExp는 현재 1/0을 표시·저장하며 성장 보너스는 없다.
- 튜토리얼은 각 상황의 확인 여부를 독립적으로 저장한다. 첫 사건이 수색이어도 이후 첫 전투 안내가 빠지지 않는다.

## 본편 데이터와 표현 범위

기존 458종에 본편의 누락된 고정 아이템 4종을 추가하여 462종을 수록했다. 본편의 동적 생성 정의 10개는 기존 추출기가 처리하지 않으므로 포함하지 않는다. 중복 UIJ_BONE은 원래 추출 규칙대로 최초 정의를 사용한다.

아이템명 449종과 설명 256종은 본편 로케일에서 가져온다. 본편에도 번역명이 없는 13종은 원본 ShortName을 사용하며 없는 설명을 지어내지 않는다. 462개 개별 아이콘을 준비했으며 직접 탐색 상자의 획득 가능 목록은 135종이다. 자세한 범위는 `ITEM_ARTWORK.md`를 참고한다. 모든 정의를 보유 아이템으로 지급하거나 모든 지역의 전리품에 넣지는 않는다.

장소 배경·NPC·적·상자·아이템은 2D 툰 이미지로 표시한다. 적의 조준·부상·엄폐는 자세별 스프라이트를 사용하며 날씨 효과는 그 위에 겹친다. 자유 이동 3D 게임은 아니며, 장소별 경로 선택과 대응 전투로 구성된다. 모바일 기기 실측 성능과 장시간 경제/난이도 조정은 별도 플레이 검증이 필요하다.

## 검증

- 파밍/첫 의뢰/서사 최종 검증: `Logs/scavenge-final-tests.xml` 총 469개 중 457개 통과. 이번 기능 관련 55개 모두 통과했고 기존 실패 12개와 목록이 동일하다. 새 첫 화면 순서와 저장 실패 복구도 Unity EditMode에서 실행했다.
- `AlphaPreview.CaptureScavengePrologue`로 1080×1920 화면 14장을 렌더링했다. 프롤로그·인물 선택·의뢰·권총 지급·상자 발견·물품 선택·획득·귀환 보고 화면을 확인했다. 미리보기의 탈출 단계는 화면 확인용으로 중간 출구 상태를 사용하며, 별도 12시드 실제 명령 시뮬레이션으로 전체 탐색을 검증한다.
- 새 기능 번역 55개씩 5개 언어 추가. 로케일 검증 18,536건 및 첫 실행 검증 13건 통과. 사용자 작업용 에디터를 유지한 채 `Library/ScavengeVerificationProject` 복사본에서 검증했다.

- 전투 처치/수색 후 `EncounterResult` 화면에서 이번 획득분의 이름·수량을 확인한다. 누적 가방과 별도 저장하며 확인 버튼 이후에만 경로 선택으로 진행한다. 결과 화면에서는 전투 시간이 멈추고, 저장 복원/반복 확인으로 전리품이 추가 지급되지 않는다. 탈출 성공 시에만 기지로 가져온다는 안내를 표시한다.
- 후속 전리품 표시 수정: Game/UI/Editor 컴파일, 독립 실행 탐색 규칙 테스트 22개 및 로케일 검증 17,320건 통과. UI 회귀 테스트는 추가·컴파일했으며, 실행 중인 Unity 에디터를 유지하기 위해 이번 수정의 Unity UI 실행 검증은 하지 않았다. 아래 전체 Unity 실행 기록은 이전 구현 시점이다.

- 최종 Unity EditMode: 총 437개, 통과 425개. 신규 25개 전부 통과; 실패 12개는 기존 실패와 동일하다. 결과는 `Logs/direct-final-tests.xml`에 있다.
- 현재 Game/UI/Editor 소스 컴파일 통과. 첫 실행 검증 13건, 로케일 검증 16,978건 통과.

- 실제 데이터로 12개 시드에서 중간 탈출 → 재출발 → 최종 탈출, 중간 저장 복원 후 같은 결과를 확인한다.
- 신규 테스트: 자원 고갈, 날씨 계수, 타이밍 엄폐, 탄약 소모, 저장 호환, 양방향 파견 차단, 중복 보상 방지, 창고 초과 보관, UI 도움말 정지, 순서와 무관한 튜토리얼, 발견 탄약 버튼 활성화, 거래 실패 롤백, NPC 귀환.
- 프리뷰: `AlphaPreview.CaptureDirectExploration`, 1080×1920, `Logs/direct-exploration-preview`.
- 기존 12개 실패는 이번 변경 전 `Logs/simple-ui-full.xml`과 이름을 비교하여 구분한다.
