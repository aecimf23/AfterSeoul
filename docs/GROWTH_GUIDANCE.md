# 첫 임무 이후 성장 안내 (2026-09-15)

## 구현
기지의 '지금 할 일' 카드가 초도 보급 완료 또는 건너뛰기 이후에도 이어진다.
- 첫 추가 장비를 실제 상점 목록에서 추천한다. 구매가/보유 자금과 구매·지급 위치를 표시한다.
- 창고에 이미 있는 장비는 다시 구매하도록 하지 않고 지급을 안내한다.
- 일반 파견 준비, 자금 마련, 복귀 대기, 부상 치료, 인원 충원을 현재 상태로 판정한다.
- 준비된 일일 의뢰는 기지 안내 카드에서 바로 납품한다.
- 부족한 의뢰 물자의 현재 수량/목표, 돈·신뢰도·경험치 보상을 표시하고 탐색·제작으로 연결한다.
- 다음 지역의 레벨·신뢰 조건과 해금 완료 여부를 실제 MapUnlock 판정으로 표시한다.
- 다른 고용주의 아직 충족되지 않은 신뢰 조건을 다음 목표로 추천하지 않는다.

안내는 보상을 추가하거나 일반 파견의 비용/위험/해금 조건을 변경하지 않는다.
여러 대기 인원 중 무장하고 비용이 낮은 인원을 기준으로 준비 가능 여부를 확인한다.
이미 다녀온 지역은 GameSave.ExploredMapIds에 기록하여 최근 20개 파견 이력이 정리되어도 다시 초행 목표로 나오지 않는다.
기존 저장은 남아 있는 일반 파견 기록에서 지역 목록을 복구한다. 이미 삭제된 과거 기록은 복구할 수 없다.

## 검증
- Unity EditMode 전체 403/403 통과. 성장 안내 회귀 8개 포함.
- 독립 성장 검사 39개 통과: 고용주 3명, 장비 구매/지급, 파견비, 복귀, 의뢰 수량/납품, 지역 추천, 읽기 전용, 저장 재접속.
- 초도 파견 회귀 120개 및 온라인/오프라인 비교 12회 통과.
- 30분 가상 진행 144회, 검사 110,882개, 복귀 비교 108회 통과.
- 실제 Unity uGUI 1080×1920 화면 9장 렌더링 및 육안 확인.
- 초도 파견 보상 설명이 잘리는 문제를 발견하여 설명 영역 높이를 140→190으로 보정.
- 재렌더링에서 새 안내 텍스트의 preferredHeight/실제 높이 검사 통과.
- UI 버튼을 통한 초도 파견 출발, 초도 납품, 일일 의뢰 납품과 이후 안내 전환 확인.
- 독립 코드 리뷰의 이력 정리/복수 인원 선택 문제를 수정하고 회귀 검사 통과.

검증은 Temp/ProgressionValidation 복사본의 숨김 Unity 프로세스에서 낮은 우선순위로 실행했다.
사용 중인 에디터와 플레이어 저장에는 접속하지 않았다.
화면 검증은 메모리 저장에 자금/물자를 넣고 지역 조건을 변경한 UI fixture다. 실제 플레이로 모든 지역을 해금했다는 뜻은 아니다.
403개 전체 테스트 이후 변경은 초도 안내 높이와 에디터 전용 잘림 검사이며, 해당 화면 재렌더링으로 확인했다.
실기기 설치·터치감·발열·장시간 재미 검증은 별도로 남아 있다.
