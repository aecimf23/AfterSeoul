# Regional quest continuations (2026-09-26)

The mobile regional introductions already cover seven maps, but only Guro, Han River and Namsan had followups. The four remaining regions now use the same two-stage followup state and the existing objective engine. Each stage must be accepted separately, then completed on a **new successful raid in that region**: stage one requires at least three moves and one item carried out; stage two requires at least four moves and two items carried out. Reporting gives the existing 20,000/30,000 won, character XP and +1 trust. Items remain with the player. The completed introduction and any saved followup stage remain intact.
