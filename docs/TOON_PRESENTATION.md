# 2D 툰 이미지와 탐색 지도 표시

2026-09-17. 메인 NPC 장면, 인물 선택, 튜토리얼, 권총 지급, 구조 귀환, 시작 화면의 ASCII 그림을 이미지로 교체했다. 본편의 직업·말투·역할을 참고한 독자적인 캐릭터 해석이며 원본 모델의 정밀 복제는 아니다.

- `Resources/ToonArt/npcs.png`: 황 상사, 최 선생, 용산 김씨. 3열, 모바일 대화창에서는 상반신으로 표시한다.

## NPC 외형 기준 (사용자 확인, 이후 재생성 시 유지)

- **보건의 최씨 / DR_CHOI는 여성이다.** 남성 의사로 그리지 않는다. 의료인으로서 실용적인 복장과 차분한 인상을 사용한다. 세부 머리 모양·복장은 이번 그림의 해석이다.
- **황 상사 / HWANG은 수염 있는 50대 남성이다.** 젊거나 수염 없는 군인으로 바꾸지 않는다. 군수 담당자의 군복·장부와 함께 중년의 얼굴, 콧수염과 턱수염이 분명하게 보여야 한다. **모자·목·가슴·어깨를 포함해 계급장은 전부 넣지 않는다.** 계급 표시 없는 군복으로 유지한다.
- **용산 킴 / YONGSAN_KIM은 본편 총기 기술자다.** 원본 `EscapeFromSeoul/Assets/Resources/Locales/ko.json`의 `TRADER_YONGSAN_KIM_DESC`는 “용산의 총기 기술자 / 총기·조준경”이다. 작업 앞치마·고글·조준경은 직업에 기반한 시각적 해석이며, 원작 외형의 정확한 복제로 주장하지 않는다.

## 기타 그림

추가 NPC 외형 기준 (사용자 수정 지시): 동대문 최씨는 40대 중반의 옷가게 주인 남성으로, 눈가·팔자 주름을 조금 더해 앳된 인상을 줄인다. 노인처럼 그리지 않는다. 도깨비는 후드 약탈자보다 건달 같은 인상으로 표현한다. 와일드맨은 거친 야외 생존 전문가지만 누더기·과한 짐·지나친 오염은 피한다. 연락책은 입꼬리를 올리지 않고 입을 굳게 다문 채, 낮고 차가운 눈매의 무표정한 군인으로 표현한다. 친근한 미소나 능글맞은 표정을 넣지 않는다. 장물아비의 후드·가려진 얼굴·출입 카드 모습은 유지한다.
- `world.png`: 4×4. 여덟 탐색 지역, 세 NPC 거점, 서울·주민·물자·도움 찾기 서사, 지하 주차장.
- `actors.png`: 4×2. 스캐브/PMC 각각 대기·조준·부상·엄폐 자세. 기존 전투 타이밍과 날씨 효과를 유지한다.
- `containers.png`: 3×2. 공구·의료·총기·탄약·포켓·금고.
- 아이템 462개와 분류용 24개도 툰 스타일로 교체했다. 활성 목록은 `ItemIcons/catalog.json`, 생성 기록은 `toon-art-prompts.json`이다.

`GameArt`가 텍스처를 로드하고 셀별 Sprite를 재사용한다. 이미지 파일을 코드로 편집하지 않으며 Unity Rect로 표시 영역만 지정한다.

직접 탐색 준비는 `RouteLockReason`이 있는 맵의 버튼 자체를 생성하지 않는다. 새 게임에는 용산 전자상가만 표시한다. 생존 귀환 순서는 용산 전자상가 → 구로 → 한강 → 남산 → 강남 → 용산 기지이며, 주요 경로 완료 후 명동·의정부를 표시한다. 잠금 조건 문구도 목록에 노출하지 않는다. 이미 열린 맵의 장비 부족·스캐브 파견 중 안내는 유지한다.

검증: 코드 컴파일 통과. 전체 EditMode 478개 중 466개 통과, 실패 12개는 변경 전 목록과 동일하다. 지도 숨김 회귀 검사는 수정 전 실패를 확인한 뒤 수정 후 통과했다. 이미지 자산 및 ASCII 호출 제거 검사도 통과했다. 실제 uGUI 1080×1920 렌더링은 `Logs/toon-direct-preview`, `Logs/toon-prologue-preview`에 보관한다.
