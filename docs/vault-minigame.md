# 정전된 지하 금고와 미니게임 UI

작업대의 무료 1단계 작업 목록에 `정전된 지하 금고`를 추가한다. 배송망 회수와 별도로 선택할 수 있다. 기본 물자는 폐자재 3개이며, 기존 창고·작업 저장·산출량 정산을 사용한다.

## 조작

- 4×4 타일을 눌러 탐색한다. 숫자는 주변 8칸의 위험 수이며 위험은 총 3칸이다.
- 첫 탐색은 안전하다. 안전 스캔은 남아 있는 안전한 칸을 찾아 열며 2회 사용할 수 있다.
- 안전한 칸 3개부터 회수 가능. 6개는 2배, 10개는 4배로 자동 회수한다.
- 붕괴 칸을 열면 추가 보수를 잃고 기본 물자로 종료한다. 종료 후 위험 위치를 1.1초 보여 준다.
- 타이머가 없는 추리/위험 선택 게임이다. 아직 모르는 칸에 대한 불확실성은 남으며, 모든 판을 추리만으로 풀 수 있다는 보장은 없다.

## 화면

공통 단말기 패널, 보상 단계 배지와 분리된 상태 영역을 사용한다. 금고는 큰 4×4 버튼과 별도의 스캔/회수 버튼을 제공한다. 배송망은 주파수 눈금, 연결률 및 추적 위험 게이지를 사용한다. 작업대 카드 높이는 게임에 따라 바뀌고 안내 문구는 줄바꿈을 허용한다.

## 검증

Game 및 Unity UI 어셈블리 컴파일 성공. VaultVerification 1,930개 검사(100개 보드의 숫자, 첫 터치, 스캔 제한, 위험, 회수 배수, 저장 왕복 및 중복 정산 방지)와 기존 DeliveryVerification 72개 검사 통과. 실제 Unity 화면 및 기기 터치 테스트는 아직 수행하지 않았다.
