# 레벨업 보상과 모바일 진행 점검 — 2026-09-26

레벨업을 실제 지원금·보급품·창고 확장으로 연결했다. 받은 보상과 다음 목표를 화면에 표시하고, 후속 의뢰가 없던 4지역에 원작을 참고한 8개 의뢰를 추가했다.

## 이번에 반영한 내용

| 항목 | 적용 결과 |
| --- | --- |
| 레벨 2~20 보상 | 각 레벨에 한 번 자동 지급. Lv2 지원금 10,000원부터 레벨마다 5,000원씩 증가 |
| 매 레벨 보급 | AI-2 구급키트·투숑카 통조림·타르콜라 각각 2개 |
| 성장 이정표 | Lv5·10·15·20마다 창고 영구 +5칸, 총 +20칸 |
| 수령 인지 | 탐색 결과의 지급 내역, 기지의 아이콘 포함 보상 확인 창, 프로필의 최근 수령 보상 |
| 다음 목표 | 프로필·탐색 결과·보상 확인 창에 다음 레벨 보상과 필요한 경험치 표시 |
| 첫 레벨업 | 첫 의뢰 경험치 100→150. 빠른 중간 탈출로 첫 의뢰를 끝내도 Lv2 도달 |
| 퀘스트 공백 | 강남·용산 기지·명동·의정부에 각 2단계 추가. 지역 후속 의뢰 총 14단계 |
| 원작 연결 | 황 상사의 강남 정찰, 기지 연락망, 장물아비의 감시받는 운반책, 와일드맨의 의정부 구조 요청을 모바일 목표로 각색 |

보상 지급과 확인은 별도로 저장한다. 여러 레벨이 한 번에 올라도 빠짐없이 지급하며, 재접속하거나 확인 버튼을 다시 눌러도 중복 지급하지 않는다. 기존 고레벨 세이브에는 누락된 레벨 보상만 한 번 지급한다. 창고에 들어가지 못한 물품은 탐색 준비 화면의 보관함에서 수령할 수 있다. 진행 초기화 시에는 새 캐릭터의 보상 기록도 함께 초기화된다.

보상 확인 창은 탐색·의뢰 대화·다른 창을 닫은 뒤 표시한다. 확인 저장에 실패하면 받은 보상은 유지하고 확인을 재시도한다. 보상 창이 열린 동안 도착한 파견 보고는 확인을 마친 뒤 이어서 표시한다.

새 의뢰는 각각 수락한 **뒤에 시작한 탐색**으로 완료해야 한다. 1차는 해당 지역 이동 3회 이상과 물품 1개 이상, 2차는 이동 4회 이상과 물품 합계 2개 이상을 지닌 생환 및 보고가 필요하다. 물품은 플레이어가 보관한다. 보상은 20,000/30,000원, 캐릭터 경험치 100/150, 담당자 신뢰 +1이다. 이전 귀환 결과로 다음 단계를 건너뛸 수 없다.

의정부 담당자는 원작 근거에 맞춰 와일드맨으로 통일했다. 기존 완료 상태와 단계, 이전에 얻은 미군 연락책 신뢰는 보존한다. 자세한 원작 파일·퀘스트 식별자와 각색 범위는 [연계 의뢰 근거](QUEST_CONTINUATIONS_2026_09_26.md)에 기록했다.

| 영역 | 확인된 상태 | 남은 보완 |

캐릭터 레벨은 개인 성장이고, 기지 레벨은 제작·일일 의뢰 티어 성장이다. 지역 해금은 생환 기록을 사용한다. 이번 변경은 레벨을 이유로 기존 지역을 다시 잠그지 않는다.

일회성 의뢰 경험치는 총 2,425이다. 모든 소개와 후속을 순서대로 완료하는 데 필요한 22회 생환 경험치까지 합산하면 약 4,185~5,725 경험치, Lv6~8 정도다. 이는 실패·추가 탐색·일일 의뢰를 제외한 계산이며, Lv20의 29,848 경험치는 장기 탐색과 일일 의뢰를 포함하는 목표다. 자동 계산만으로 장기 재미와 난이도를 확정하지 않았다.
