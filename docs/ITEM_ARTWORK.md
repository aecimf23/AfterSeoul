# 아이템 개별 아이콘과 확장 파밍

2026-09-17 본편 `EscapeFromSeoul/Assets/Scripts/SeoulLogic/ItemDatabase.cs`와 모바일 `items.json`을 대조했다. 양쪽 모두 고정 ID 462개이며 누락 ID는 없었다. 중복 정의 `UIJ_BONE`은 추출기의 기존 규칙대로 첫 정의를 사용한다. 기존 등록 물품을 실제 파밍에 추가했으며 중복 ID를 만들지 않았다.

## 현재 적용된 개별 그림

- `Assets/Resources/ItemIcons/toon-catalog-01.png` ~ `toon-catalog-12.png`: 1536×1024 투명 RGBA, 8열×5행. 462개 아이템 각각 고유 셀. 마지막 시트의 18칸은 비어 있다.
- 장비 110개, 의료품 26개, 식량 43개, 탄약 33개, 보관함 10개, 기타 240개. 현재 장착하지 못하는 야간투시경·부착물·특수 도구, 의정부 재료·설계도·시설, 퀘스트 물품도 포함한다.
- `catalog.json`이 ID → 시트/좌표를 연결한다. `ItemArtwork.For(ItemDef)`가 개별 그림을 우선하고, 분류용 아이콘이나 미등록 ID에만 2D 툰 스타일의 24종 분류 그림을 사용한다. 텍스처 지연 로드와 Sprite 재사용을 적용했다.
- 본편 이름·슬롯·설명에 맞춰 만든 독자적인 일러스트이며 본편 모델의 정밀 복제본은 아니다.
- 생성 모드: 내장 `image_gen`. 최초 프롬프트는 `docs/item-artwork-prompts.json`, 수정 프롬프트는 `docs/item-artwork-corrections.json`, 툰 스타일 변환은 `docs/toon-art-prompts.json`에 기록했다.
- `Tools/Measure-ItemArtwork.ps1`은 PNG 픽셀을 읽기만 하여 투명 행 여백 좌표를 기록한다. 그림 파일 자체를 수정하지 않는다.
- 검색 미리보기: `docs/item-artwork-gallery.html`. `Tools/build_item_artwork_gallery.py`로 만들며 원본 PNG를 참조한다.
- `Tools/prepare_item_artwork.py`는 전체 시트 재생성용 명세 작성기다. 기존 시트를 재생성하지 않은 채 실행하면 셀 순서가 바뀔 수 있다. 신규 아이템은 기존 배치를 보존한 별도 시트에 추가한다.

## 파밍 확장

직접 탐색 상자의 고정 목록 29종을 가중 추첨 135종으로 확장했다. 총기상자는 지원 총기·근접무기·장착 가능한 방탄복/헬멧/가방/리그/헤드셋, 탄약상자는 자연 출현 AMO 탄약, 의료상자는 현재 회복 효과가 있는 의료품, 포켓은 식량/음료/기초 의료품, 공구상자는 부품·원단·공구, 금고는 GPU·시계·귀중품 등을 제공한다.

`LootContainers.AvailableIn`이 적합성을 판단한다. 원본 자연 출현 가중치 0인 제작/이벤트 전용품과 퀘스트·열쇠·의정부 전용품은 일반 상자에서 제외한다. 미지원 장비는 아이콘만 미리 준비한다. 본편 `spawnWeight`를 사용하며 가격 25,000/60,000/150,000원 이상은 가중치를 각각 2/4/8로 나눠 비싼 물건의 빈도를 낮춘다. 고가 공구는 1개, 저가 재료는 2~4개, 탄약은 10~20발이다. 서로 다른 두 선택지에서 하나를 고르는 흐름과 기존 저장된 선택지를 유지한다.

스캐브 파견의 기존 맵 보상표, 가격·장비 능력치, 본편 배송 정책은 변경하지 않았다.

검증: 전체 EditMode 478개 중 466개 통과, 기존 실패 12개와 동일. `ExpandedLootTests`는 24,000회 상자 샘플링에서 135종 접근·퀘스트품 제외, 소총별 다른 그림, 462개 고유 셀과 모든 셀의 실물/투명 배경/캐시를 검사한다. `AlphaPreview.CaptureExpandedItemArtwork`는 실제 uGUI 창고·서로 다른 소총 상세·방어구 선택·획득 결과를 1080×1920으로 렌더링한다.

## 이전 24종 대표 시트: 분류/대체 그림으로 유지

`Assets/Resources/ItemIcons/toon-survival-atlas.png`는 생성한 일러스트를 실제 프로젝트에 저장한 투명 RGBA 스프라이트 시트다. 1536×1024, 가로 6칸 × 세로 4칸으로 각 셀은 256×256이다. 모두 굵은 선과 단순한 색면의 2D 툰 스타일을 사용한다. 이미지의 보이지 않는 RGB 영역에는 생성 도구의 배경 색이 남아 있으나 알파가 0이며, Unity에서는 투명하게 표시된다.

| 행 | 왼쪽부터 6개 |
|---|---|
| 1 | 권총, 소총, 근접 칼, 탄약, 구급 파우치, 붕대 |
| 2 | 주사기와 약병, 통조림, 물병, 음료수 캔, 렌치, 볼트와 너트 |
| 3 | 회로기판, 배터리, 전선, 금속판, 방탄복, 헬멧 |
| 4 | 배낭, 문서, 열쇠, 귀중품, 기계 부품, 테이프 |

`ItemArtwork.KindOf(ItemDef)`가 아이템 식별자/장착 슬롯/기존 분류로 대표 형태를 고른다. 총 462개 각각의 고유 모델을 그린 것은 아니며, 기본 권총·붕대·생수처럼 눈에 띄는 차이를 분리하고 나머지는 분류별 대표 그림을 공유한다. 분류·아이템 데이터·경제 수치는 바꾸지 않는다.

`Ui.Icon`은 아이템 정의 또는 분류를 받아 컬러 그림을 표시한다. 기존 단색 테마 틴트를 적용하지 않으며, 자산이 없을 때만 기존 선 아이콘으로 대체한다. 텍스처 한 장과 최대 24개 스프라이트를 공유·캐시한다. 밉맵을 끄고 원본 크기를 보존하여 작은 아이콘에서 옆 셀의 색이 번지지 않도록 한다.

그림이 명목상 셀 경계를 조금 넘는 마지막 행은 실제 투명 여백(위에서 250·506·744px)을 기준으로 잘라, 위 행에 배낭이나 열쇠 조각이 섞이지 않게 한다. 원본 이미지는 변경하지 않는다.

적용 위치: 창고 목록/상세, 탐색 전리품과 귀환 결과, 파밍 물품 선택, 제작 레시피/완료, 의뢰 요구 물품.

검증: `ItemArtworkTests`는 모든 셀의 실물·투명 배경·캐시 재사용과 전체 아이템 매핑을 검사한다. `AlphaPreview.CaptureItemArtwork`는 창고·붕대 상세·권총 상세·파밍 선택·획득 결과를 1080×1920으로 렌더링한다.
