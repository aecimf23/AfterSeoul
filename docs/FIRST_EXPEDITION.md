# 초도 보급 파견 — 구현 및 검증 (2026-09-15)

## 플레이 흐름
기존 제작 → 판매 → 첫 고용 이후, 탐색 화면의 **초도 보급 · 첫 출동** 카드에서 무기를 든 대기 인원 1명을 선택한다.
- 명동 보급 경로, 3분, 비용 0원. 전투·부상·실종·장비 손실이 없다.
- 일반 지역 전리품 대신 임무용 보급 꾸러미 1개를 회수한다.
- 기지의 지금 할 일 카드에서 납품하면 50,000원을 한 번 받는다. 자동 지급이 아니다.
- 완료 후 인원 화면의 장비 구매·지급을 안내한다. 이후 일반 파견부터 기존 비용과 위험 규칙이 적용된다.
- 초도 보급 전에 일반 파견을 시작하면 지원을 건너뛴다. 탐색 카드에 이 내용을 표시한다.

## 저장 호환
GameSave.Orientation은 기존 저장에서 null이다. 고용주가 유효하고 레벨 2 이하, 파견 기록과 인원별 파견 경험이 없는 저장만 Pending으로 초기화한다.
진행한 저장은 Skipped로 초기화하며 진행 중인 일반 파견의 시간·결과를 바꾸지 않는다.
기존 스키마 2에 선택 필드를 추가했다. 새 파견의 IsOrientation은 출발 시 저장한다.
임무 물자는 창고가 아닌 Orientation.HasCargo로 보관하므로 창고 포화·판매·일일 의뢰 갱신과 독립적이다.
납품 시 상태와 화폐를 같은 저장에 반영한다. 기존 파일 저장의 원자적 교체 경로를 사용한다.

## 검증 결과
- Tools/Run-OrientationVerification.ps1: 120개 검사, 온라인/오프라인 비교 12회 통과.
  - 179초 미복귀 / 180초 복귀, 무기 없는 팀·중복 인원·잘못된 인원 거절
  - 중복 출발·납품 거절, 재접속 후 납품, 재접속 후 중복 지급 방지
  - 창고 용량 0에서 임무 물자 보존, 인원·장비 안전 복귀
  - 초반/진행 저장 마이그레이션, 기존 일반 파견 복귀까지 비교
  - 오프라인 비교에 임무 단계와 물자 소유 상태 포함
- Tools/Run-OrientationSimulation.ps1: 144회, 검사 110,882개, 복귀 비교 108회 통과.
  - 고용주 3명 × 행동 정책 4개 × 시작 시간 변형 12개
  - 빠른 제작: 36/36 초도 납품, 시작 후 7분 5초~7분 50초
  - 보통 제작: 36/36 초도 납품, 10분 5초~11분 35초
  - 느린 제작: 36/36 초도 납품, 19분~19분 5초
  - 자동 생산 큐만 사용: 0/36, 30분 안에 첫 고용 자금에 도달하지 못함
  - 종료 자금으로 장비 구매·지급 및 재료 제작/중간 재접속 확인
- 기존 Unity 컴파일 응답 파일을 별도 출력 폴더로 복사해 최신 코어 및 Unity UI 전체 소스 컴파일 통과.
- 독립 코드 리뷰 후 검증의 잘못된 저장 선택과 임무 상태 비교 누락을 보완하고 재실행.

실제 게임 C# 소스와 가상 시계를 사용하는 검증이다. 사람의 손 플레이나 독립적인 사고 확률 표본은 아니다.
기존 395개 Unity EditMode 전체 테스트, 새 화면 렌더링 및 Android APK 재빌드는 이번 변경 후 실행하지 않았다.
현재 PC 사용을 방해하지 않도록 Unity 창/입력 조작 없이 검증했다. 이번 기능의 실기기 가독성·터치 확인은 남아 있다.
