# 끊어진 배송망

폐자재 회수(RCP_SALVAGE)의 선별/힘주기/타이밍 3단계를 배송망 해킹 한 판으로 교체한다. 재료 없이 시작하며 나머지 제작법과 자동 생산은 유지한다.

- 작업 버튼을 누르면 수신 바늘이 오른쪽으로, 떼면 왼쪽으로 움직인다. 움직이는 밝은 신호 안에 유지하면 화물을 확보한다.
- 일반 배송 → 기업 보안 화물 → 기밀 회수 화물 순서로 신호 폭이 좁아지고 추적 위험이 커진다.
- 각 단계에서 회수 또는 추가 도전을 선택한다. 결정 화면은 8초 후 안전하게 회수한다. 최대 추적 시간은 35초.
- 기본/2배/4배 산출량. 추가 도전 중 실패하면 추가 보수만 잃고 기본 물자는 받는다. 손가락 조작에 따라 결정되며 랜덤 당첨은 없다.
- 실제 아이템은 기존 작업 정산 및 창고 용량 규칙을 통해 지급한다. 화면만 배수를 표시하는 것이 아니다.
- 기존 폐자재 공정 중간 세이브는 새 한 판의 시작으로 정리한다. 비용 없는 공정이므로 재료 손실은 없다.

Core/DeliverySignal은 Unity 없이 시뮬레이션할 수 있다. Tools/DeliveryVerification.cs는 추적 성공, 회수, 재도전 실패, 4배 보수, 타임아웃, 구버전 공정 정리, 저장 왕복과 중복 정산 방지를 확인한다. 게임 및 UI 코드는 컴파일 검증했으나 Unity 실기기 터치/화면 테스트는 별도로 필요하다.
