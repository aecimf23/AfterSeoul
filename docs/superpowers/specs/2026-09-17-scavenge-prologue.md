# 파밍과 첫 의뢰

사용자 요청: 이동 중 빈 사건을 없애고 공구·의료·총기·탄약 상자, 포켓, 금고에 따른 파밍 선택을 추가한다. 서울 주민이 도시 안정화까지 남아 생존하기로 결심하고, 혼자 살 수 없어 약탈자들에게 들은 실권자를 찾아가는 이미지 서사 뒤에 인물 선택을 연결한다. 선택한 인물의 서사에 맞는 첫 의뢰가 직접 탐색으로 이어져야 한다.

## 결정

- 기존 6~10 사건/전투/생존 귀환/본편 경로를 유지한다. 장소별 경로에 상자 단서를 표시하고 다음 사건의 상자 종류를 결정한다. 비전투는 상자 발견 → 두 물품 중 선택 또는 빠른 회수 → 획득 결과. 적을 피한 경우에도 주변 상자 탐색으로 이어진다. 전투 승리는 기존 전리품 결과를 유지한다.
- 선택 후보는 진입 때 저장해 재접속으로 재추첨하거나 반복 지급할 수 없다. 상자별 실제 아이템 풀과 수량을 사용한다. 의료/탄약은 바로 다음 전투에도 쓸 수 있다.
- 첫 실행 서사는 4장 일러스트로 구성한다: 무너진 일상, 서울에 남는 결심, 혼자서는 부족한 물자, 실권자를 찾아가는 길. 기존 Unity 그림 구성 요소로 간단한 도시/주민/물자/갈림길 그림을 만들어 외부 이미지 의존 없이 모바일에서 선명하게 표시한다. 첫 실행에 인물 선택보다 먼저 표시하고 페이지를 저장한다. 기존 플레이어에게 강제 재생하지 않는다. 설정에서 다시 볼 수 있다.
- 인물 선택은 배속 메뉴 대신 찾아갈 사람을 정하는 대화로 표현한다. 황 상사는 물자 회수로 능력을 확인하고, 보건의 최씨는 의료 물자/지역 확인을 부탁하고, 용산 김씨는 수리 물자를 확인한다.
- 첫 의뢰 상태(제안/수락/보고 가능/완료)는 직접 탐색과 독립적으로 저장한다. 수락 → 기존 권총 지급 대화 → 용산 탐색. 목표는 각 NPC에 맞는 상자 수색 후 생존 귀환. 첫 의뢰 중 첫 사건에 해당 상자를 보장한다. 사망 시 미완료; 재시도 가능. 보고 보상은 일회 지급하고 완료 대사를 표시한다.
- 홈에 첫 의뢰 한 줄과 보고 버튼, 준비/탐색에 목표를 짧게 표시한다. 기존 제작/파견 튜토리얼보다 첫 의뢰를 우선 안내한다.
- 한국어를 포함한 기존 5개 언어, 저장 롤백, 재접속, 예전 저장 호환을 유지한다.

## 검증

상자별 후보 유형·재추첨 방지·단일 회수·회피 후 파밍·경로 상자 연결, NPC별 첫 의뢰 수락/실패/성공/일회 보상, 프롤로그 선행·저장/재실행 및 UI 첫 실행 흐름을 확인한다. 실행 중인 사용자 Unity 에디터를 종료하지 않는다.
