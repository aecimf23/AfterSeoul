# 직접 탐색 설계 초안

상태: 사용자 승인 후 첫 플레이 가능 구현 완료. 구현 결과와 검증은 docs/DIRECT_EXPLORATION.md 참고. 밸런스 값은 후속 플레이 검증에서 조정한다.

## 목표와 구현 방식

장비 준비 → 지역 선택 → 6~10개 랜덤 구간 → 상황 선택/실시간 교전 → 전리품 확보 → 탈출의 한 판을 만든다. 기존 제작과 스캐브 파견은 보조 성장 수단으로 유지한다.

권장 방식은 배경 장면과 적의 동작을 보여주는 선택형 탐색이다. 자유 이동 3D 방식은 조작과 콘텐츠 제작 범위가 크게 늘어난다. 텍스트 전용 방식은 구현이 가볍지만 적의 동작을 보고 대응하는 요구를 충족하지 못한다.

## 한 판의 흐름

- 출발 시 6~10개 구간 길이와 난수 상태를 저장한다. 전투 입력 횟수는 구간 수에 포함하지 않는다.
- 해금된 지역 중 진행 중인 스캐브 파견이 없는 곳에만 진입한다. 직접 탐색 중인 지역으로 새 스캐브를 파견하는 것도 막는다.
- 각 구간은 스캐브, PMC, 빈집/매장 수색, 물자 발견 등의 사건이다. 선제 발견/상호 발견/기습당함에 따라 선택지와 전투 시작 상태가 달라진다.
- 사건이 끝나면 목적지가 명확한 길 두 개를 보여준다. 예: ‘1층 매장으로’, ‘주차장으로’. 내부 노드 번호를 화면에 노출하지 않는다.
- 중간 탈출구는 3번째부터 마지막 직전 사이에 적어도 한 번 등장한다. 이 구간에서는 두 길 아래에 ‘물건을 챙겨 탈출’ 버튼이 추가된다. 계속 이동하면 해당 탈출 기회는 지나간다.
- 마지막 구간 뒤에는 확정 탈출구가 있어 추가 구간이 무한 생성되지 않는다. 탈출 자체는 이동 자원을 요구하지 않는다.
- 구간이 바뀌면 장소 배경, 환경음/시각 효과와 가능한 사건이 바뀐다. 용산은 매장·통로·주차장 등 실명 장소로 구성한다.

## 장비와 생존 자원

- 플레이어는 기존 스캐브의 무기·머리·방탄복·헤드셋·리그·가방 구조를 공유한다. 별도 근접 슬롯을 추가하여 총과 칼을 함께 장착할 수 있도록 한다. 기존 스캐브 저장 데이터는 호환한다.
- 장착은 창고 물건을 실제로 이동시키며 다른 인원과 같은 아이템을 중복 사용하지 않는다. 슬롯은 한 화면에 보이고 선택하면 호환 장비 선택창을 연다.
- 플레이어 HP, 수분, 에너지는 탐색 밖에서도 저장한다. 출발 전 회복/보급을 제공하며 탐색 진입으로 자동 초기화하지 않는다.
- 출발 시 가져간 치료제·음식·음료는 창고에서 탐색 가방으로 이동한다. 탐색 중 사용은 해당 가방에서 차감한다.
- 이동마다 수분·에너지를 소모한다. 에너지 0이면 일반 이동을 막고 음식 사용 또는 긴급 귀환을 제공해 막힌 상태를 방지한다. 낮은 수분은 조준 회복을 늦춘다. 둘 다 0이면 강제 귀환한다.
- 정상 탈출은 획득 물건 전부를 보존한다. **적용 규칙:** 사망/긴급·강제 귀환은 장착 장비와 남은 출발 보급품을 보존하되 이번 탐색에서 새로 얻은 전리품은 잃는다. 정상 탈출과 실패 귀환을 결과 화면에서 명확히 구분한다.

## 교전

- 실시간 상태: 경계 → 조준 예고 → 사격 → 재장전/엄폐, 피해 시 부상 반응. 적의 자세와 짧은 문구가 함께 다음 행동을 알린다.
- 하단에 공격·엄폐/회피·아이템·근접의 최대 네 행동만 표시한다. 근접 무기가 없으면 해당 행동은 숨긴다.
- 총기에 허용된 단발/점사/연사만 제공한다. 피해량·발사 지연·명중률·탄 소모를 구별한다. 기존 무기 등급만으로 발사 모드를 추측하지 않고 별도 전투 프로필을 정의한다.
- 사격 예고에 맞춘 엄폐가 피해를 줄인다. 엄폐는 지속 시간과 재사용 시간이 있어 무한 회피를 막는다. 적이 엄폐하면 사격 효과가 줄고 회복할 기회가 생긴다.
- 치료에는 시간이 걸리므로 노출 상태에서 사용하면 피격 위험이 있다. 적 격파 시 탐색 가방에 보상이 한 번만 들어가고 다음 길 선택으로 넘어간다.
- 맑음·비·안개를 제공한다. 비는 양측 청취/발견 거리를, 안개는 양측 사격 명중률을 동일한 함수로 낮춘다. 날씨 배경 효과와 현재 영향 한 줄을 표시한다.
- 도움말, 앱 백그라운드 진입 시 전투를 정지한다. 재개 시 같은 적 상태와 남은 예고 시간을 복원하여 보이지 않는 동안 피해받지 않게 한다.

## 모바일 화면과 안내

- 홈의 중심 행동은 ‘직접 탐색’. 오늘의 할 일은 기존처럼 작은 요약으로 유지한다.
- 탐색 화면 상단: HP와 작은 수분/에너지 표시. 중앙: 장소와 적. 하단: 짧은 상황 설명과 현재 가능한 선택지.
- 길 선택 두 개, 탈출구 발견 시 세 번째 버튼. 전투 중에는 같은 하단 영역이 전투 버튼으로 바뀐다. 경로/전투 메뉴를 동시에 늘어놓지 않는다.
- NPC 튜토리얼은 장비 장착 → 첫 이동 → 발소리 선택 → 사격 예고/엄폐 → 보상 → 탈출 순으로 실제 행동에 맞춰 한 단계씩 보여준다. 도움말 재생 가능.

## 데이터와 검증

### 결과 화면과 NPC 구조 연출

- 정상 탈출: 녹색 ‘생존하여 귀환에 성공했습니다!’ 문구, 캐릭터 레벨, 탐색 장소, 확보한 아이템 아이콘·이름·수량을 표시한다. 목록은 길어지면 스크롤된다.
- 사망: 같은 화면 구조에서 빨간색 ‘당신은 사망했습니다.’ 문구를 표시한다. 마지막 치명타를 가한 상대의 이름/스캐브·PMC 구분/무기와 사망 원인을 탐색 결과에 저장하고 표시한다. 환경 원인이라면 적을 임의로 표시하지 않는다.
- 사망 결과에는 획득 확정 보상과 분리하여 ‘잃어버린 전리품’을 표시한다. 생존 결과와 같은 목록이라도 보관된 것으로 오해하지 않게 한다.
- 자원 고갈에 따른 강제 귀환은 사망으로 표시하지 않고 ‘탈진하여 구조되었습니다’로 구분한다.
- 결과 확인 → 화면이 검게 페이드아웃 → 홈으로 전환 → 페이드인 순서로 진행한다. 사망/탈진 귀환 시 사용자가 선택한 메인 NPC의 초상과 구조 대사 및 주의 메시지를 표시한다. 예: ‘간신히 데려왔어. 다음엔 무리하지 마.’ 정상 탈출에는 무사 귀환 대사를 사용한다.
- 사망 후 조작 가능한 상태로 회복시키되, 보급까지 자동 충전하지 않는다. 구조 시 HP 최소값을 보장하며 귀환 후 치료/보급으로 이어진다.
- 결과 화면을 닫거나 앱을 재실행해도 정산과 구조 이벤트가 중복 발생하지 않도록 결과 ID와 확인 상태를 저장한다. 페이드 중 입력은 잠근다.

### 독립적인 캐릭터 레벨

- 현행 Player.Level/Exp는 지역·의뢰·고용 해금에 이미 쓰인다. 이를 변경하거나 초기화하지 않는다.
- 별도 CharacterLevel(초기 1), CharacterExp(초기 0)를 저장한다. 캐릭터/장비 화면과 탐색 결과에서 ‘캐릭터 Lv.1’로 표시한다.
- 이번 범위는 레벨 저장·표시 구조까지다. 경험치 지급, 성장 곡선, 레벨 보상, 능력치 및 해금 연결은 추가하지 않는다. 따라서 이번 구현에서 탐색 결과에 가짜 경험치 증가를 연출하지 않는다.

### 창고와 본편 아이템 목록

- 모바일 items.json에 본편 추출 아이템 458종이 이미 존재한다. 기존 Tools/extract_mainline_data.py를 기반으로 본편 데이터와 대조하며 본편 ID를 유지한다. 아이템 정의가 있다고 모든 아이템을 창고에 지급하지는 않는다.
- 이름·설명은 본편 로케일에서 재사용한다. 전투/치료/음식 효과와 아이콘은 추출 및 모바일 로더 지원 여부를 별도로 확인하고 필요한 필드만 보완한다. 임의의 가짜 설명이나 수치를 본편 정보로 표시하지 않는다.
- 창고 상단은 용량과 간단한 종류 필터, 하단 대부분은 아이콘·이름·보유 수량을 보여주는 세로 스크롤 목록으로 구성한다.
- 아이템을 탭하면 상세 팝업을 연다. 이름, 큰 아이콘, 설명, 관련 성능과 가능한 행동을 보여준다. 판매 수량 선택/판매 및 기존 본편 전송 기능은 이 팝업에 유지한다.
- 팝업을 닫으면 목록 스크롤 위치와 필터를 유지한다. 팝업 안의 버튼을 누르기 전에는 아이템 탭만으로 판매·사용·장착되지 않는다.
- 많은 보유 아이템에서도 목록 조작이 느려지지 않도록 필요한 행만 갱신하고, 상세 설명을 모든 행에 펼치지 않는다.

- GameSave에 플레이어 생존/장비 및 ActiveExploration 상태를 추가한다. 기존 저장에는 안전한 기본값을 채운다.
- 독립적인 탐색 진행·전투 판정·정산 로직을 Game 계층에 두고 Unity UI는 표시와 입력만 담당한다. 기존 자동 파견 판정은 유지한다.
- 난수 결과, 현재 구간, 적 상태, 소모품, 전리품, 정산 여부를 저장해 재접속으로 사건을 다시 뽑거나 보상을 중복 수령하지 못하게 한다.
- 창고가 가득 차면 탈출 보상은 미수령 보관함에 남긴다. 물건을 조용히 버리지 않는다. 저장 실패 시 성공 표시 없이 재시도할 수 있게 한다.
- 검증: 구간 수 6~10, 중간/최종 탈출 보장, 파견 중복 차단, 장비 수량 보존, 날씨 양측 대칭, 전투 타이밍, 자원 고갈 후 탈출 가능, 강제 귀환, 보상 단회 정산, 재접속, 구형 저장, 모바일 화면 잘림을 확인한다.
- 추가 검증: 생존/사망/탈진 결과 구분, 치명타 상대 기록, 선택 NPC 대사, 구조·정산 단회 실행, 기존 해금 레벨 불변, 아이템 팝업과 스크롤 위치 복원, 본편 아이템 ID 일치.
