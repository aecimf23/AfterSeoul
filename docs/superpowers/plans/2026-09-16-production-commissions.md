# 용산킴 시제품 의뢰와 제작 장비

사용자의 추가 요구를 현재 생산 공장에 이어 구현한다. 단순 즉시 해금을 시제품 의뢰로 바꾸고, 제작 장비/업그레이드로 자금 사용처와 인원 배분 선택을 만든다.

## 확정 구현 방향
- 첫 P17과 첫 고용 지원은 유지한다. 이후 24개 총기는 기존 해금 금액을 **보유금 조건**으로 사용한다. 조건은 의뢰 접수 자격이며 접수 때 돈을 차감하지 않는다. 장비 제작/강화가 실제 자금 소모처다.
- 조건 충족 → 용산킴 의뢰 대화 → 수락 → 목표 총기 시험 제작 → 시제품 납품 → 보수 지급 + 정식 해금. 시제품은 창고/본편 전송 대상이 아니다. 낮은 품질을 실패 조건으로 삼지 않는다.
- 목표 수량은 처음 3정, 이후 단계적으로 최대 8정. 시제품은 목표 수량까지만 만들고, 보수는 납품 시 한 번 지급한다. 접수만으로 정식 해금되거나 오프라인 초과 생산으로 제한을 우회할 수 없다.
- 시험 총기는 의뢰가 있는 동안만 선택할 수 있다. 기존 승인 총기와 왕복 가능하나 총기 변경 시 현재 미완성 작업량은 기존 정책대로 초기화한다. 완료 시제품 수량은 유지한다.
- 조립 지그: 클릭 효율 증가. 동력 공구: 스캐브 작업 속도 증가. 추가 작업대: 배치 한도 증가. 첫 1자리는 무료이며 옛 저장에서 이미 배치한 인원은 보존한다. 기존 전체 속도 업그레이드도 유지한다.
- 인원은 공장/파견에 동시에 배치할 수 없다. 설비 화면에서 대기/파견/공장 인원을 구별하고 배치 한도, 장비 효과, 다음 강화 비용을 표시한다.
- 용산킴 어투 참고: 본편 ko.json의 QUEST_Q_YONGSAN_01_ACCEPT, QUEST_Q_DONGDAEMUN_03_ACCEPT/COMPLETE, QUEST_Q_YONGSAN_KIM_GUNSMITH_1_ACCEPT/COMPLETE. 실용적 기술자, 작업 결과와 작동 검증 우선, 허세/과장 배제. 신규 대사는 AfterSeoul 전용이다.
