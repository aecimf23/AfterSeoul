# 컨베이어 타이밍 생산

사용자 요청: 무제한 연타 생산을 제거하고, 작업대 위로 지나가는 총기 부품이 판정 구간에 왔을 때 눌러 작업량을 얻는다. 업그레이드는 더 많은/더 높은 등급 부품이 등장하는 방향으로 개편한다.

- 기존 시제품 의뢰, 납품, 첫 고용 지원, 스캐브 오프라인 생산은 유지한다.
- 화면의 실제 이동 ASCII 부품과 코어 판정이 같은 위치를 사용한다. 부품당 한 번만 성공할 수 있으며, 너무 일찍 누르면 해당 부품을 놓친다. 빗나간 입력에는 짧은 회복 시간이 있어 난사로 판정 창을 덮을 수 없다.
- 수동 부품은 생산 화면이 활성일 때만 시간 진행하며 탭 이동/재접속으로 생산 보수를 얻지 않는다. 자동 생산은 기존 타임라인으로만 정산한다.
- 저장된 SpeedLevel은 공급 설비 단계로 재해석하여 등장 간격을 줄인다. AssemblyJigLevel은 재료 선별 장치 단계로 재해석하여 상위 등급 부품을 해금/증가시킨다. 기존 구매 단계와 비용은 보존한다. 동력 공구/작업대의 자동 효율·인원 한도는 유지한다.
- 기본/개량/정밀/특수 부품은 서로 다른 ASCII와 색, 표시 작업량을 갖는다. 등급과 입력 타이밍 모두 진행도에 실제 반영한다.
- 코어 타이밍/중복/난사/강화 테스트와 실제 UI 입력 테스트를 수정한다. 모든 기존 의뢰 검증은 타이밍에 맞춰 입력하도록 바꾸고, UI/코어/번역/실제 화면/Android 빌드를 검증한다.

작업 분담: 코어 담당은 판정·세션·밸런스·독립 검증, 부모는 컨베이어 UI·강화 설명·UI 테스트·미리보기, 번역 담당은 새 문구의 5개 언어를 맡는다.
