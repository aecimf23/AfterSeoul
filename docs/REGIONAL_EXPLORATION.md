# 지역 인물 소개와 탐색 연출

본편 `EscapeFromSeoul/Assets/Resources/Locales/ko.json`의 상인 설명·대사·첫 정찰 의뢰를 참고한 모바일용 각색이다. 본편 전체 의뢰 및 표식 설치 시스템을 이식한 것은 아니다.

| 탐색 지역 | 담당 인물 |
|---|---|
| 구로 폐공단 | 동대문 최씨 |
| 한강 세관 | 도깨비 (용산 킴의 소개, 본편 밀수로 설정) |
| 남산 숲 | 와일드맨 (황 상사의 소개) |
| 강남 | 황 상사 |
| 용산 기지 | 미군 연락책 |
| 명동 | 장물아비 |
| 의정부 | 미군 연락책 |

기존 용산 첫 의뢰는 유지한다. 아직 열린 적 없는 지역은 목록에 표시하지 않는다. 열린 지역의 첫 선택에서 소개 인물의 연락 → 담당 NPC의 요구 → 의뢰 수락으로 이어진다. 수락만으로 출발 물자를 소비하지 않으며, 준비 화면에서 다시 지역을 선택해 출발한다. 지역별 의뢰는 두 번 이상 이동하고 물품을 가지고 생존 귀환한 뒤 보고한다. 보상은 지역당 한 번 15,000원과 담당 NPC 신뢰 +1이다. 지도 개방은 기존 생존 귀환 순서를 유지한다.

`RegionalExplorationQuests`는 수락·보고 가능·완료를 저장한다. 이전 탐색을 소급해 완료시키지 않는다. 저장 실패 시 기존 `ExecuteSavedAction` 복구를 적용한다. 원본 고정 NPC ID를 사용하며 새로운 상점이나 NPC 능력치는 추가하지 않는다.

`ToonArt/regional-npcs.png`는 3×2 그림으로 동대문 최씨·도깨비·와일드맨·미군 연락책·장물아비를 표시한다. 원본 대사의 직업·성격에 기반한 새 시각적 해석이며 확인되지 않은 원작 외형의 복제로 주장하지 않는다. 기존 최씨의 여성 설정과 황 상사의 50대·수염·계급장 없음 설정을 유지한다.

적 표시 조건은 HP가 0보다 크고 교전 중이거나 발견된 인카운터일 때뿐이다. 결과 및 길 선택 단계에서는 `Detected`가 남아 있더라도 이전 적을 표시하지 않는다. 적 정보는 전리품·결과에 필요하므로 데이터 자체를 삭제하지 않는다.

`Audio/Exploration`의 효과음은 본편 `Resources/sfx`에서 복사했다. 발소리 두 종류, 권총·소총·산탄총, 재장전 시작·완료, 근접, 피격, 쓰러짐, 천 마찰(엄폐·물품 사용), 물품 사용 완료가 있다. 단발·점사·연사는 실제 소비한 탄 수에 맞춰 1·3·5회 재생한다. 저장된 명령이 성공하거나 전투 시간이 실제로 진행됐을 때의 상태 변화로만 재생하며, 화면 재표시에는 재생하지 않는다. 기존 효과음 음량·음소거 설정을 따른다.

검증 기록: `Logs/regional-exploration-tests.xml` 491개 중 479개 통과, 기존 실패 12개와 목록 동일. 실제 uGUI 1080×1920 렌더링 9장 `Logs/regional-contacts-preview`에서 NPC 소개·의뢰 및 적이 없는 길 선택 화면을 확인했다. Android ARM64 IL2CPP 개발 APK 빌드 성공, 오류 0·기존 Unity Services 프로젝트 미연결 경고 1. `Builds/Android/AfterSeoul-alpha.apk`(187,880,308바이트), 로그 `Logs/regional-android-build.log`. 실기기 설치·오디오 청취 검증은 별도다.
