# 첫 동료 지원과 시작 동선 — 2026-09-16

## 플레이 흐름

고용주 선택 → 한 화면의 짧은 안내 → 무료 회수 실습 1판 → 고철 1개 판매 → 첫 1티어 동료 선택 → 기존 3분 무료 안전 파견 → 꾸러미 납품 50,000원.

- 배송망/지하 금고 중 어느 쪽이든 한 판 완료하면 실습으로 인정한다. 실패도 인정한다. 큐 생산과 작업 취소는 실습 완료가 아니다.
- 실습 이후 고철(JUNK16)을 1개 이상 정상 판매하면 지원이 열린다. 창고 안내에서 1개 판매를 바로 실행할 수 있다.
- 고용주가 첫 1티어 계약금 전액을 부담한다. 현금을 지급하거나 차감하지 않으며 판매 수익은 남는다. 후보는 플레이어가 고른다. 기본 무기도 기존 고용 규칙대로 지참한다.
- 지원 전에도 자금이 있으면 정상 고용할 수 있다. 유료/지원 중 어떤 경로로든 첫 고용에 성공하면 지원은 종료된다. 이후 인원 상실·날짜 갱신·재접속으로 다시 열리지 않는다. 2티어 이상은 지원 대상이 아니다.
- 공장 첫 작업 버튼을 사용할 수 있다. 작업을 고르면 게임판이 일시정지 상태로 먼저 표시되고 작업대로 스크롤이 이동한다. 명시적으로 시작하기 전에는 시간과 판 조작이 진행되지 않는다.
- 배송망은 시작한 첫 누름부터 유지 입력을 받는다. 힘주기의 기존 동작은 유지한다. 금고는 시작 후 보드 버튼으로 조작한다.
- 공장/창고/인원/기지에서 실습 → 판매 → 지원 고용의 현재 단계를 안내한다. 고용 후 탐색 화면으로 연결한다. 설정의 기존 상세 안내 다시 보기는 유지한다.

## 저장 호환

스키마 2에 선택 필드 `GameSave.Starter`를 추가했다. 실습·판매 완료와 지원 종료 상태를 기존 세션 저장 경로로 보관한다.

유효한 고용주가 있고 초도 보급이 Pending인 기존 저장 중, 인원·고용 완료 후보·파견·탐색 이력이 없는 경우 지원을 초기화한다. 초도 보급 상태가 없는 오래된 저장은 기존 Orientation 초기화 조건(레벨 2 이하 등)을 따른다. 기존 돈·물자·진행 중인 작업은 보존한다. 이미 고용/파견한 저장이나 초도 보급을 종료한 저장에는 소급 보상을 지급하지 않는다.
