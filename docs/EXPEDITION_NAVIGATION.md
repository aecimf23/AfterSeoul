# 탐색 화면 개편 — 2026-09-16

## 화면 흐름

지역 지도 → 지역 상세 → 팀 편성 및 최종 파견으로 나눈다. 지도의 지역 버튼만 누른 상태에서는 인원을 보내지 않는다. 각 단계의 뒤로 버튼으로 지역 선택이나 상세 정보로 돌아간다.

원작 `EscapeFromSeoul/Assets/Scripts/SeoulLogic/Program.Views.Progression.cs`의 `DrawMapSelection`은 지도 노드와 선택 지역 상세 패널을 사용한다. 모바일에서는 이를 단계별 화면으로 옮기고 기존 `maps.json` 위치 관계를 터치 간격에 맞춰 조정했다. 원작 지도 자체는 ASCII이므로 가져오지 않고 선·면으로 그리는 `FieldMap`과 버튼을 사용한다. 상세 설명은 본편에서 가져온 `MAP_*_DESC` 번역을 사용한다. 파견 시간·비용·사고 확률은 AfterSeoul 기준이다.

## 지역 표시

- `IDataRegistry.AllMaps`에 등록된 7개 파견 지역만 대상으로 한다. 오래된 `maps.json.mvp` 플래그로 분류하지 않는다.
- `MapUnlock.IsUnlocked`가 false인 지역은 지도 버튼과 마커를 생성하지 않는다. 레벨/신뢰도가 올라 조건을 만족하면 나타난다.
- 인원·무기·자금은 지역 준비 화면에서 실제 출발 판정으로 확인한다. 지역을 고르기 전에 팀 선택이 없어도 열린 지역의 상세 정보는 볼 수 있다.
- 첫 명동 파견은 기존 무료 3분 안전 초도 보급으로 연결한다. 해당 지역 상세에 지원 내용을 표시하고 일반 파견 비용과 혼동하지 않게 한다.
- 구조 요청은 지도 아래에 위치 확인 버튼을 두고, 해당 지역 상세에서 구조 대상 확인 → 팀 편성 → 구조 파견으로 이어진다.

## 진행 중인 파견

지도에서 각 지역 바로 아래에 파견 팀 수, 가장 빠른 복귀 예정 시각(KST), 남은 시간을 표시한다. 여러 팀이 있으면 해당 지역 상세에 각각의 인원 이름, 복귀 예정 시각, 남은 시간, 진행률과 진행 막대를 표시한다. 다른 지역의 파견과 이미 정산된 파견은 상세 목록에서 제외한다. 남은 시간과 진행률은 매 프레임 갱신한다.
