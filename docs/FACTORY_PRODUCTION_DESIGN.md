# 용산킴 생산 공장

승인된 요구: 공장을 생산/설비로 구분, 생산 화면 상단 절반에 플레이어와 작업장 ASCII, 본편 권총부터 총기 순차 해금, 클릭 생산과 속도 업그레이드, 대기 스캐브의 공장 배치. 총기는 용산킴에게 자동 납품하고 작업비를 받는 방식으로 사용자 확정.

## 동작
- 공장 안의 생산 공장/설비 공장 선택. 생산은 상단 약 절반을 고정 작업장 장면으로 사용하고 하단에 총기 선택, 진행도, 클릭 작업, 작업비와 업그레이드 접근을 표시한다.
- 재료는 용산킴 제공. 완성품은 자동 납품되며 창고·장비·본편 전송 아이템으로 생성하지 않는다. 모든 고용주 선택에서 이용 가능하다.
- WPN04 P17부터 모바일에 존재하는 본편 총기 25종을 명시적 순서로 해금한다. 이름과 식별자는 기존 ItemDef에서 읽고 아트는 기존 본편 자산을 우선 조사하여 사용한다. 별도 총기 아트가 없으면 같은 총기를 표현한 모바일 ASCII를 만든다.
- 이동하는 ASCII 부품이 중앙 구간에 왔을 때 누르면 작업량이 오른다. 부품마다 한 번만 성공하며 빗나가면 다음 부품을 잃고 회복을 기다린다. 회복 중 연타는 회복을 늦춘다. 공급 강화는 부품 공급 간격과 배치 인원의 자동 작업 속도를 개선한다. 다음 총기는 보유금 조건을 채우면 용산킴의 시제품 의뢰를 받을 수 있고, 3~8정을 완성해 납품하면 보수와 정식 제작 승인을 받는다. 접수 시 돈을 차감하지 않으며, 시제품 보수는 직접 납품할 때 한 번 지급한다.
- 첫 총기 완성/자동 납품은 첫 고용 실습과 판매 체험을 대체하며 기존 일회성 1티어 계약금 지원을 연다. 이전 미니게임 경로도 계속 지원한다.
- 설비에는 의뢰/제작 장비/인원 배치/부품 작업대 메뉴를 둔다. 재료 선별 장치는 고급 부품의 공급 비중, 동력 공구는 자동 생산 효율, 추가 작업대는 배치 한도를 올린다. 첫 배치 1자리는 무료다. 기존 유료 보조 인력은 보존하고 총기 생산 인원에 중복 합산하지 않는다.
- 진행 중인 시험 총기는 승인된 총기와 전환할 수 있다. 총기 전환 시 미완성 작업량은 초기화하되 완성 시제품은 보존한다. 목표 수량에 도달하면 시제품 생산은 멈추고 납품을 기다린다. 정식 승인을 받기 전에는 시험 총기를 무제한 자동 납품할 수 없다.
- Idle 스캐브만 공장 배치 가능. 배치 중에는 파견 불가, 해제 즉시 대기 복귀. 부상/치료/실종/사망/파견 인원은 배치 불가. 비용·작업 속도를 바꾸기 전 현재까지 정산한다.
- 배치 인원은 오프라인에도 선택한 총기를 자동 생산한다. 기존 오프라인 상한을 적용하고 정산을 다시 호출해도 중복 보수가 생기지 않는다. 미완성 작업량을 저장하며 해금/속도/인원/총기 변경 시 과거 시간에 새 속도를 소급하지 않는다.

## 변경 경계와 검증
초기 자동 작업량은 1인당 초당 0.01로 둔다. P17 기준 시간당 평균 18,000원으로, 명동 기본 파견의 예상 순수익 약 37,260~76,680원/시간(3~4회 회수, 사고·장비·사건·고용주 보너스 제외)보다 낮게 잡아 위험 없는 배치가 파견을 압도하지 않게 한다. 첫 제작은 기본 부품 10회 성공으로 5,000원과 첫 고용 지원을 받는다. 공급 강화의 기존 자동 작업 1.2배 배율은 유지한다. 재료 1~4등급은 작업량 +1/+2/+3/+5이며 기존 조립 지그 구매 레벨은 재료 선별 장치로 계승한다. 수동 컨베이어는 생산 화면에서만 흐르며 오프라인 진행을 지급하지 않는다.

AfterSeoul만 변경한다. 코어는 Unity 비의존, 밸런스는 balance.json, 선택 상태는 GameSave.Factory.Production에 선택 필드로 추가한다. ScavStatus에 끝 값으로 Working을 추가해 기존 숫자 저장과 호환한다.

첫 제작/작업비, 순차 해금, 속도 개선, 부당 배치 거절, 파견 상호 배제, 재접속/중복 정산, 장기 오프라인 상한, 기존 저장·부품 공장 보존을 검증한다. 실제 uGUI 상단 아트 영역과 버튼들을 렌더링하고 Android 패키징까지 확인한다.

## 작업장 연출·사운드·3인 배치 (2026-09-16)
- 플레이어 + 스캐브 최대 3명의 작업대를 한 화면에 표시한다. 실제 배치 인원의 이름과 서로 다른 머리 장비, 대기/망치 올리기/타격/회복 ASCII를 사용한다. 빈 자리는 빈 작업대로 구분한다.
- 추가 작업대는 2단계까지 제작하여 총 3명을 배치한다. 이전 저장의 3명 초과 배치는 앞의 유효 인원 3명을 유지하고 나머지는 대기로 돌린다. 인원을 삭제하거나 파견 상태를 바꾸지 않는다.
- 스캐브는 기존 시간 기반 생산을 계속한다. 동작은 진행 상태를 보여 주는 연출이며 추가 보수를 만들지 않는다. 자동 작업률, 소수점 두 자리 진행도와 다음 완성까지 남은 시간을 표시한다. 현재 시험 총기 목표 달성 시에만 동작을 멈춘다.
- 수동 성공 타격과 스캐브 타격 프레임에 금속 망치 소리, 총기 완성에 본편 장전 완료 소리, 미스에 공구 미끄러짐 소리를 낸다. 자동 타격은 수동보다 작게 재생한다. 공장에는 본편 Cold Iron Floor 음악을 사용하며 탭 전환 시 부드럽게 바뀐다.
- 메인 화면 진입 시 선택한 고용주의 인사를 상단 초상화 옆에 표시한다. NPC별 2개 대사, 글자 등장에 맞춘 본편 퀘스트 대사음, 30초 반복 제한을 적용한다. 첫 안내/설정/복귀 보고 중에는 기다리며 다른 탭에서는 인사가 멈춘다. 용산킴 시제품 대사에도 같은 소리를 적용한다.
- 효과음/음악 설정과 음소거를 유지한다. 음원 출처와 생성한 망치 파형은 AUDIO_SOURCES.md에 기록한다.
- Unity EditMode 429개, 제작 코어 474개, 컨베이어 196개, 언어 초기화 13개와 번역 리소스 15,496개 통과. 실제 1080×1920 화면 18장: Logs/workshop-preview/.
- 작업장 연출 버전 Android 빌드 및 APK 서명 검증 성공. 기록: `Builds/Android/workshop-audio-package-result.txt`. 실기기 설치·스피커 청음은 미실시.

- 고용주 세 명과 공장 작업 인물을 윤곽선이 선명한 2D 애니메이션풍 이미지로 교체했다. NPC 장소도 같은 스타일로 맞췄다. 원본을 보존하며 새 파일과 생성 기록은 `MOBILE_ART.md`에 있다.
- 실제 작업 인원만 중앙에 배치한다. 혼자일 때 작업대 하나만 보이고, 스캐브 배치/해제에 맞춰 2~4개 작업대가 가운데 정렬된다. 미배치 작업대는 숨긴다.
- 생산 화면을 세로로 내려 다음 총기 의뢰 조건, 부품 공급 강화, 재료 선별 장치, 동력 공구, 추가 작업대를 한 목록에서 확인·구매한다. 기존 설비 화면에서도 같은 구매 함수를 사용한다. `제작 장비 ↓`는 목록 첫 의뢰 카드로 이동하고, 상단 `생산 공장`은 조립 영역으로 돌아간다.
- 구매 금액·장비·의뢰 상태가 같으면 장비 목록을 재생성하지 않아 일반 타격 중 버튼과 스크롤 위치를 유지한다. 제작 수익·장비 구매·시제품 완성 후에는 상태를 갱신한다.
- Unity EditMode 442개 통과 (`Logs/anime-layout-all.xml`). 실제 구매/의뢰 수락, 미배치 작업대 숨김과 중앙 정렬, 장비 바로가기 첫 카드 도착과 갱신 후 스크롤 유지를 확인했다. 스크롤 위치 테스트는 수정 전 실패(447px 어긋남)와 수정 후 통과도 확인했다.
- 실제 uGUI 화면 27장 (`Logs/anime-factory-preview/`)을 캡처해 혼자/3인 배치와 목록 첫 카드·하단 장비를 확인했다. Android 빌드 성공(오류 0), APK 서명 검증 통과. 패키지 기록은 `Builds/Android/anime-factory-package-result.txt`. 실기기 플레이는 미실시다.
